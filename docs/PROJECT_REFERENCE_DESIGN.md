# C# 프로젝트 참조 설계

## 가져오기와 경로 식별

`CSharpProjectReader`는 폴더 열기 또는 Git 가져오기가 확보한 XML을 읽습니다. 문서 외부 엔터티와 DTD를 차단합니다. Git은 기록한 HEAD의 `ls-tree` 결과와 `cat-file --batch`로 읽은 객체를 사용합니다. 참조 선언에서 발견한 경로는 확보한 프로젝트 경로 사전에서 조회합니다.

경로 사전의 키는 로컬의 정규 절대 경로 또는 Git의 루트 기준 경로입니다. Windows 로컬은 대소문자를 구분하지 않고 Git은 구분합니다. Git 경로는 슬래시와 경로 요소로 해석합니다. 사용자가 보는 경로에는 가져온 파일 이름을 사용합니다. 폴더가 다른 동일 파일명의 프로젝트는 각각 고유한 노드와 어셈블리 식별자를 받습니다.

직접 선언한 무조건부 `<ProjectReference Include="../Core/Core.csproj" />`의 고정 상대 경로를 지원합니다. `ItemGroup`과 참조 항목의 조건, 동적 경로, 절대 경로, 목록, 와일드카드, 루트 밖 경로, C# 외 대상과 추가 평가를 요구하는 메타데이터는 연결을 보류합니다. `Remove`나 `Update`가 있으면 프로젝트 참조 전체의 연결을 보류합니다. 개별 파일 선택에서는 가장 가까운 프로젝트의 지원 설정을 읽고 참조 탐색은 폴더 가져오기에서 수행합니다.

## 그래프와 Roslyn 분석

1. 정규 경로가 같은 참조를 하나로 모으고 확보한 XML을 대상으로 간선을 구성합니다. 누락, 읽기·XML 해석 실패, 파일 수와 용량 제한에 따른 생략을 구분합니다. 알려진 생략 프로젝트의 디렉터리는 기본 컴파일 파일 소유권의 경계로 유지합니다.
2. Tarjan 알고리즘으로 강결합 요소를 찾습니다. 정점 하나의 자기 간선과 여러 정점의 순환을 감지합니다. 순환에 속하는 프로젝트가 대상인 간선을 보류하고, 나머지 간선으로 의존 대상이 먼저 나오는 순서를 만듭니다.
3. 프로젝트별 소스, 언어 버전, 전처리 기호를 사용해 `CSharpCompilation`을 준비합니다. `ToMetadataReference()`로 확보한 소스의 컴파일 참조를 전달합니다. 소비자가 전이 의존 프로젝트의 공개 타입을 직접 사용하거나 중간 프로젝트의 공개 시그니처로 받는 경우에도 해당 참조를 사용할 수 있습니다. 다이아몬드의 공통 참조는 한 번만 추가합니다.
4. 참조 대상의 확보한 컴파일 소스가 없으면 연결을 보류합니다. 읽기 실패나 컴파일 진단이 있는 대상의 사용할 수 있는 선언은 분석에 활용하고 부분 연결 사유가 상위 소비자에게 전파됩니다. 참조가 연결된 분석 문맥에서 Roslyn SemanticModel로 정적 규칙과 실제 메서드 CFG를 분석합니다.

노드는 최대 128개입니다. XML은 프로젝트당 256 KiB이며, Git은 합계 2 MiB 제한을 적용합니다. 프로젝트당 정규 참조 경로를 최대 256개 기록하므로 실제 노드 간 간선은 최대 16,384개입니다. 강결합 요소 탐색과 순서 계산은 각각 정점과 간선 수에 비례하며 가져오기 취소를 확인합니다. Roslyn의 참조 대상 추가 진단에는 전체 20초 검증 시간을 적용합니다. 시간 안에 확인하지 못한 참조는 부분 연결로 표시합니다.

## 결과와 범위

연결 상태는 기존 `AnalysisIssue`를 사용합니다. 확인된 연결은 정보 항목이며 분석 성공 상태를 유지합니다. 부분 연결과 보류는 분석 제한 항목으로 집계합니다. JSON v1은 정보 항목에 선택 필드 `isInformational`을 저장합니다. 이전 이력에서 필드가 빠진 경우 기존 분석 제한으로 복원합니다. Excel의 기존 분석 한계 및 참고사항 시트에서 참조 상태를 표시합니다.

지원 문맥은 정적 분석을 위한 소스 집합입니다. 실제 MSBuild 평가와 빌드, NuGet 복원, 프로젝트 산출물 생성·실행, 소스 생성기, 대상 프레임워크별 참조 팩, 다중 대상 프레임워크 선택 및 별칭·어셈블리 이름 설정은 범위 밖입니다. 기존 런타임 참조와 로컬 범위 안의 관리형 `HintPath`를 사용합니다. 확인할 수 없는 형식은 영향을 받은 메서드의 CFG 제한 또는 참조 대상 진단으로 표시합니다.
